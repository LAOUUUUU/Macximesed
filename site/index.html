Macximesed update channel

This site is what macx checks for updates. It holds one signed file, channel/v1.json, with its Ed25519 signature, v1.json.sig.

  • macx checks once a day and tells you when a new version is out. Updating is up to you.
  • If your version is marked unsafe (minimumSafe), macx updates itself before the next command.
  • Every file is signed in a protected release step. macx rejects anything with a bad signature, an older sequence number, or a download whose SHA-256 doesn't match.

Source and releases: github.com/LAOUUUUU/Macximesed
